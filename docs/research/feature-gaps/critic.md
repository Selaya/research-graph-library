## Feature areas the digest was thin on

- Voice-over / audio-sync authoring: the library explicitly documents 'fitting holds to a recorded voice-over' as a first-class use case (docs/RECORDING.md), but no cohort addresses audio-timeline sync, waveform display, or caption/transcript tooling for this library's own advertised feature
- Storyboard/cue-sheet DSL depth: the library's serializable op-array with labels, seek-by-label, and per-step 'dur' pacing is a distinctive feature only shallowly compared (one generic 'keyframe scripting language' line vs Motion Canvas) rather than against structured narrative-script formats like Lottie/Bodymovin JSON or scripted Ken-Burns/pan-zoom tools
- Live-mode event-log replay + time-travel scrub: loosely compared only against full orchestrator apps (Airflow, Temporal UI) rather than against lighter embeddable replay/time-travel tools (XState inspector, Redux DevTools time-travel) that are closer analogs and were present in the digest but under-examined
- SVG-native export/asset pipeline: since the library is SVG-based and DOM-inspectable, no cohort assesses SVG export fidelity, poster-frame/static-snapshot export, or print/PDF rasterization from SVG - export gaps are scattered thinly (one ECharts saveAsImage line, PDF export under commercial-diagramming) without ever being pointed at this library's own SVG output path
- Zero-dependency bundle-size competitiveness: the library explicitly touts 'no dependencies at all since M3' for its in-house layout engine as a differentiator, but no cohort quantifies or compares bundle size / CDN single-file footprint against comparable no-framework libraries, despite this being a stated selling point
- Compound-node meta-edge aggregation semantics (dedup + weighted rollup on collapse) - touched generically in cytoscape-sigma's expand-collapse item but never checked against comparable rollup features such as AntV G6 combo layouts or Grafana Node Graph grouping

## Gaps flagged as dubious

- **Force-directed layout listed as [missing]/[unverified] independently across at least five cohorts (cytoscape-sigma, vis-echarts-plotly, antv-g6-x6, d3-and-layout-engines, large-scale-and-analytics, animation-and-presentation) with inconsistent fit scores (1 to 3) for what is the same underlying gap**: duplicating one real gap six times inflates the apparent gap count and the contradictory fit scores (fit 1 in d3-and-layout-engines vs fit 3 elsewhere) suggest the scoring wasn't normalized against a single fixed notion of this library's remit
- **pipeline-orchestrator-uis items like 'Backfill visualization', 'Historical duration trend analytics', 'Live log streaming per node/step', and 'Manual retry-from-failed-node' scored at fit 4-5 as strong-fit missing features**: these require a running execution backend and persisted run history that a client-side rendering/animation library is not positioned to have; scoring them as strong-fit gaps conflates 'could render this if fed the data' with 'is missing a capability it was never meant to own,' and no comparably-scoped client-only library elsewhere in the digest (e.g. react-flow-family) is penalized this way for lacking backend/analytics features
- **text-to-diagram cohort's ~15 diagram-type/DSL items (Gantt, mindmap, ER/sql_table, UML/class diagrams, UI wireframe/Salt, text DSL authoring itself) almost all marked [missing]**: mermaid and friends are static declarative text-to-image renderers, a fundamentally different product category from this library's imperative, stateful, animation-driven JS API; nearly every item is [missing] by definition since the library has no text-DSL parser at all, making the cohort mostly low-signal noise that dilutes higher-value findings rather than a targeted feature comparison
- **commercial-diagramming's 'Framework wrapper packages (official React/Angular/Vue components)' listed as [missing], echoed again at lower fit in react-flow-family**: the library's README states 'no framework, no build step' as its core value proposition in the second line - absence of React/Angular/Vue wrappers is a deliberate design choice, not a gap, and the inconsistent fit scores between the two cohorts (fit 3 vs fit 1) for the identical claim show it wasn't evaluated against the library's actual stated goals
