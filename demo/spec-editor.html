Interactive spec editor — edit the JSON, watch the difference animate

The left pane is the graph's own spec, as JSON, plus a storyboard script. Apply never remounts: it diffs what you typed against g.spec() into one list of addNode / removeNode / addEdge / removeEdge / update ops, dry-runs that whole list through g.validate(ops), and only then replays the very same list inside one g.batch() — so every id you kept keeps its DOM node and tweens into place. Misuse — a dangling edge, a loop:true edge with no maxIterations — comes back from validate() as a list of GraphErrors with their codes, and nothing is committed at all.
