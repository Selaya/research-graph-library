What to look for
  • The dashed loop-back arc from Observe to Think — its badge ticks iter 1/6 → 2/6 → 3/6 as the agent keeps going.
  • A caption under the graph naming the exact tool call each iteration reaches for (iteration 2: read_file src/auth.js), paired with a highlight pulse on the active tool.
  • Act is a collapsed container — the story expands it to reveal its three tool children (search / read_file / run_tests), each with its own declared duration. It declares its ports (entry/exit: [search, read_file, run_tests]), so the edge into it fans the token out to all three tools and Observe joins on the whole set.
  • Click any tool node to read its declared duration in the last tool call tile — that is g.on('nodeclick'), not a hand-rolled pointer handler.
  • Once the loop's iteration budget for this run is spent, the token leaves via Observe's own out-edge — not the loop edge — to Final answer.

Legend — dashed arc = the loop edge (loop:true, maxIterations:6, this run rides it for 3), pulsing outline = the highlighted/active element. Zoom is ctrl/⌘ + wheel; a click on a container toggles it directly.
