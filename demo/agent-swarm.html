Multi-agent research swarm — fan-out, a count-join, and a bounded revision loop

A planner agent fans out to five worker agents — literature search, code search, data pull, expert interviews and a benchmark run — each running at its own declared duration. One worker (data pull) hits a rate limit, retries twice on its own budget (data.fail:{reason,retries:2}) and then fails for good, so the synthesizer is declared join:{count:4}: it fires once the four surviving branches land, never waiting on the fifth. A critic then reviews the synthesis and can bounce the plan back to the planner for revision — a bounded loop, maxIterations:3 — before the swarm hands off a reviewed final report. Zoom is ctrl/⌘ + wheel; plain scroll pans.

  • Fan-out — one planner token spawns five worker tokens at once.
  • The retrying worker — data pull fails, spends its two retries (one fail event each, terminal:false), then fails for good; the workers container rolls up to failed too, even though the other four keep going.
  • The count-join firing — synthesizer needs only 4 of 5 arrivals to fire.
  • The loop iteration badge — revise plan ticks on the planner, up to 3 times.
  • The final report — the critic's forward edge hands off once revisions are spent.
