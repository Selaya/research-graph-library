sparkle-motion-visualizer — demos

A small, embeddable, animated graph visualization library — built for narrating pipelines of work: steps appearing over time, tokens flowing through fan-outs and joins, retry loops ticking, manual steps condensing into automated ones, and a transport bar to play, pause, and scrub the whole story. One <script> tag, no build step, no framework. Below: the flagship story, nine animated sequence diagrams, eighteen use-case demos across software delivery, AI agents, streaming data, business operations and tooling, and the engineering demos the library grew up on. Every page runs on the same dist/smv.iife.min.js. View the repo on GitHub →

Flagship

Featured demo

SDLC release pipeline: from manual to automated

Jira ticket → branch → PR & code-review loop → merge → per-device build & signing → QA + regression fan-out across device types → per-device deploy → GA — with manual phases condensing into automated ones as the story plays out.

OAuth authorization code + PKCE, then a token refresh

Timeouts, retries, and a circuit breaker

Group chat delivery

Cache-aside: miss, fill, hit

A distributed trace, replayed live
