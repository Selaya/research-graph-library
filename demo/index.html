sparkle-motion-vizualizer — demos

A small, embeddable, animated graph visualization library — built for narrating pipelines of work: steps appearing over time, tokens flowing through fan-outs and joins, retry loops ticking, manual steps condensing into automated ones, and a transport bar to play, pause, and scrub the whole story. One <script> tag, no build step, no framework. View the repo on GitHub →
