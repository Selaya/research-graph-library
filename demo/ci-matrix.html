CI/CD matrix build — a pull-request run, one failing leg

A PR triggers checkout → a cached install → a 6-way build matrix (5 OS/runtime combos plus lint) fanning out inside one collapsible container, all AND-joining into a required gate check. windows/node20 fails partway through with a real symlink error, so the gate never sees all six arrivals and the run stalls there — exactly what a red PR check looks like. Integration tests (with a bounded flaky-retry loop) and the preview publish sit downstream, wired up but unreached this run.
