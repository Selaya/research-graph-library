LLM evaluation harness — a prompt eval run that fails, retries, and passes

A candidate prompt set fans out to 6 held-out test cases; each case's model output is scored by its own LLM judge; the six verdicts join:"all" into a score aggregation step feeding a threshold gate. The first run's gate fails — two cases score badly, and pass@1 lands under the 0.80 bar — so it loops back to Revise prompt (a bounded retry, maxIterations:3). A revised prompt v2 re-runs the same harness and clears the bar; the gate turns green.
